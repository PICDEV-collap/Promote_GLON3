# ตัวดูแลบอทสำหรับการให้บริการลูกค้าจริง

เพิ่มวันที่ 4 ตุลาคม 2569 หลังพบโปรเซสบอทหาย แต่เบราว์เซอร์ GLO และ tunnel ยังอยู่ ไม่พบ fatal error ใน log จึงยังยืนยันต้นเหตุการหยุดไม่ได้

## พฤติกรรม

- Windows Task Scheduler ชื่อ `Promote_GLON3-BotSupervisor` ตรวจทุก 1 นาที แยกจากโปรเซสบอทและหน้าต่างผู้พัฒนา
- เมื่อโปรเซสบอทหายและพอร์ตว่าง เปิดเฉพาะบอทกลับ พร้อมเก็บ log เดิมและอัปเดต PID
- ต้องมี browser และ tunnel ที่ตรวจยืนยันว่าเป็นของโปรเจกต์นี้อยู่ก่อน ไม่สร้าง tunnel ใหม่หรือเปลี่ยน webhook
- ไม่ยึดพอร์ตโปรเจกต์อื่น ไม่หยุดโปรเซสที่ยังทำงาน และไม่ส่งออเดอร์ค้างซ้ำ
- หากบอทยังอยู่แต่ health ไม่ผ่าน 3 รอบ จะเตือน Telegram ให้ตรวจออเดอร์ก่อนรีสตาร์ต
- จำกัดการเปิดกลับ 3 ครั้งในช่วง 10 นาที หากถึงเพดานจะเตือนและรอจนพ้นช่วงเวลา ไม่วนเปิดไม่หยุด
- แจ้ง recovery/ข้อผิดพลาดผ่าน Telegram พร้อมลดการแจ้งเหตุซ้ำ ไม่ใช้ LINE Push
- `n3-engine` เมื่อสั่งหยุดจะสร้าง `bot-service/data/supervisor-paused`; เมื่อสั่งเริ่มจะเอาสถานะพักออก

## ติดตั้งและตรวจ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-bot-supervisor.ps1
Get-ScheduledTask -TaskName Promote_GLON3-BotSupervisor
Get-ScheduledTaskInfo -TaskName Promote_GLON3-BotSupervisor
```

ไฟล์สถานะ: `bot-service/data/supervisor-state.json` และ log: `bot-service/data/diagnostics/supervisor.log` ไม่ commit ข้อมูลเหล่านี้

หยุดเพื่อบำรุงรักษาโดยตั้งไฟล์ `supervisor-paused` ก่อน หรือ Disable-ScheduledTask สำหรับ task นี้เท่านั้น เมื่อต้องการเปิดกลับ ให้ใช้เมนูเริ่มระบบ หรือเอาไฟล์พักออกและเปิด task นี้กลับ ห้ามปิดบริการของโปรเจกต์อื่น

## ข้อจำกัด

- งาน scheduled task ใช้บัญชี Windows ปัจจุบันและทำงานระหว่างที่บัญชีเข้าสู่ระบบ เครื่องดับ/Windows logoff/ไม่มีอินเทอร์เน็ตยังให้บริการไม่ได้
- กู้คืนเริ่มในการตรวจรอบถัดไปประมาณไม่เกิน 1 นาที บวกเวลาเปิดบอท ไม่ใช่รับประกันไม่มี downtime
- คิวเดิมอยู่ใน RAM; หากโปรเซสตายกลางออเดอร์ต้องเทียบ GLO กับคำสั่งซื้อก่อนส่งซ้ำ ตัวดูแลไม่ replay รายการให้
- ไม่มีการทดสอบโดยจงใจทำให้บอทลูกค้าจริงล้ม ผลทดสอบใช้เงื่อนไขจำลองและตรวจ scheduled task แบบอ่านสถานะ
- ต้องพัฒนาคิวถาวรและ reconciliation เพิ่มเพื่อกู้ธุรกรรมกลางทาง และทดสอบไฟดับ/รีบูตในช่วงบำรุงรักษา
