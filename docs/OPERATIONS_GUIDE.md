# 📖 คู่มือการใช้งานและการดูแลระบบ (Operations & Administration Guide)

คู่มือนี้จัดทำขึ้นสำหรับเจ้าของร้านและผู้ดูแลระบบร้านสลาก N3 ธนกิจนำโชค เพื่อการเปิดใช้งาน ควบคุม ตรวจสอบ และดูแลรักษาบอทอย่างมีประสิทธิภาพ

---

## 1. จุดเริ่มต้นใช้งานด่วน (Quick Start Launchers)

ภายในโฟลเดอร์หลักของโปรเจกต์ มีตัวเปิดใช้งานที่อำนวยความสะดวกให้ผู้ดูแลระบบบน Windows:

| ไฟล์ Launcher | วัตถุประสงค์การใช้งาน | ลักษณะการทำงาน |
| :--- | :--- | :--- |
| **`N3-MANAGER.bat`** | **แผงควบคุมหลัก (Master Dashboard)** | เปิดเมนูคอนโซลสำหรับดูสถานะ, ดูโควต้า, เปิด/ปิดบอท, ล้างไฟล์ขยะ, และดู Webhook URL |
| **`START-BOT-HIDDEN.vbs`** | **เปิดบอทในเบื้องหลัง 100% (Silent Mode)** | รันบอทและ Cloudflare Tunnel เงียบๆ ไร้หน้าต่างสีดำกวนสายตา เหมาะสำหรับการใช้งานประจำวัน |
| **`START-BOT-SILENT.bat`** | **เปิดโหมดเงียบผ่าน Batch** | เรียกใช้ `START-BOT-HIDDEN.vbs` แล้วปิดตัวลงทันที |
| **`START-BOT.bat`** | **เปิดบอทพร้อมหน้าจอ Log สด** | เปิดคอนโซลแสดงการทำงานสด เหมาะสำหรับการทดสอบหรือดูข้อความแชทแบบเรียลไทม์ |
| **`STOP-BOT.bat`** | **หยุดการทำงานของบอททันที** | ปิดโพรเซสของบอทและ Cloudflare Tunnel คืนพอร์ต 3333 สะอาดเรียบร้อย |
| **`RESTART-BOT.bat`** | **รีสตาร์ทบอทโดยไม่เปลี่ยน Webhook URL** | รีสตาร์ทเฉพาะตัว Node.js โดยคง Cloudflare Tunnel เดิมไว้ ไม่ต้องไปเปลี่ยน Webhook ใน LINE |
| **`UPDATE-BOT.bat`** | **อัปเดตโค้ดและรีสตาร์ท** | คอมไพล์ TypeScript (`npm run build`) แล้วรีสตาร์ทบอทในเบื้องหลัง |
| **`CREATE-DESKTOP-SHORTCUTS.bat`** | **สร้างทางลัดบน Desktop** | วางไอคอนทางลัดสำหรับเปิด/ปิดบอทไว้บนหน้าจอ Desktop ให้อัตโนมัติ |

## 2. การควบคุมผ่านแชท LINE แอดมิน (In-Chat Admin Commands)

ผู้ดูแลระบบสามารถสั่งการบอทได้โดยตรงจากห้องแชท LINE ส่วนตัว (ตาม `LINE_ADMIN_USER_ID` ที่ตั้งไว้ใน `.env`):

| คำสั่งที่พิมพ์ใน LINE | การทำงานของบอท |
| :--- | :--- |
| `qr` หรือ `login` | บอทจะส่งภาพ QR Code สำหรับล็อกอินระบบตัวแทน GLO ผ่านแอปเป๋าตังมาให้ในแชท |
| `เช็คโควต้า` หรือ `โควต้า` | ดูยอดสลากที่ขายแล้วและยอดคงเหลือจริงจากกองสลาก (เต็ม 2,000 ใบ) |
| `ทดสอบเลขมงคล` | ขอดูตัวอย่างการ์ด Flex Message สุ่มเลขมงคลเปิดดวงประจำงวด |
| `ส่งเลขมงคล` | สั่งบรอดแคสต์ส่งเลขมงคลกระจายไม่ซ้ำให้ลูกค้าทุกคนทันที |
| `ทดสอบผลรางวัล` | ขอดูตัวอย่างการ์ด Flex Message ประกาศผลรางวัลสลาก N3 |
| `ส่งผลรางวัล` | สั่งบรอดแคสต์ส่งผลการออกรางวัลสลาก N3 ให้ลูกค้าทุกคนทันที |
| `ลูกค้าทั้งหมด` | สรุปยอดลูกค้าทั้งหมดในระบบ (จำนวน Active และ Blocked) |

## 3. การบำรุงรักษาและการแก้ปัญหา (Maintenance & Troubleshooting)

### 3.1 ตรวจสอบสถานะการทำงาน
* เปิด `N3-MANAGER.bat` แล้วเลือกเมนู **[3] 🎫 ตรวจสอบสถานะและโควต้า**
* ตรวจสอบว่าพอร์ต 3333 กำลัง Listen อยู่ และ Tunnel เชื่อมต่อสถานะ Active
* หรือเปิดเบราว์เซอร์เข้าดูสถิติระบบได้ที่: `http://localhost:3333/api/campaign/stats`

### 3.2 เมื่อเซสชันของกองสลากหมดอายุ (Session Expired / Kickout)
1. เมื่อเซสชันหลุด บอทจะแจ้งเตือนเข้ามาใน LINE แอดมินโดยอัตโนมัติ
2. แอดมินเพียงพิมพ์คำว่า `qr` ในแชท LINE ของร้าน
3. บอทจะจับภาพ QR Code สำหรับเข้าสู่ระบบตัวแทนส่งกลับมาให้ในแชท
4. แอดมินเปิดแอปเป๋าตัง แล้วสแกน QR Code เพื่อเข้าสู่ระบบได้ทันทีโดยไม่ต้องเปิดคอมพิวเตอร์

### 3.3 การล้างไฟล์ขยะและรูปภาพเก่า
* เปิด `N3-MANAGER.bat` แล้วเลือกเมนู **[4] 🧹 ล้างไฟล์ขยะและคืนหน่วยความจำ**
* หรือพิมพ์คำสั่ง `clean` ในคอนโซลของบอท เพื่อลบภาพ QR Code ชำระเงินเก่าที่หมดอายุแล้ว

### 3.4 การอัปเดต LINE Rich Menu
หากต้องการปรับปรุงผังปุ่มหรือสีของ Rich Menu บน LINE:
1. แก้ไขเทมเพลตใน `scripts/setup-richmenu.js`
2. รันคำสั่ง `node scripts/setup-richmenu.js`
3. สคริปต์จะเรนเดอร์ภาพใหม่ อัปโหลดไปยัง LINE CDN และเปลี่ยนเป็นเมนูเริ่มต้นให้ลูกค้าทุกคนอัตโนมัติ
